Travailler sur le code en local

La boutique en ligne utilise déjà la configuration Firebase injectée au déploiement. Pour cloner le dépôt et lancer l’app sur votre machine, vérifiez d’abord ces prérequis dans la console Firebase du projet :

  • Realtime Database créée (mode production) — URL utilisée par le template.
  • Authentication : activer au minimum Google (connexion à /admin) ; l’e-mail / mot de passe est recommandé selon votre usage.
  • Cloud Storage activé — le plan Blaze est souvent requis pour Storage ; sans bucket configuré, les envois logo / favicon depuis l’admin échouent. Le nom du bucket peut se terminer par .appspot.com ou .firebasestorage.app selon les projets.

Remplacez VOTRE_DEPOT dans les commandes de l’étape suivante par le nom du dépôt GitHub fourni (format up2date-it/nom-du-depot).
